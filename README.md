# Research Radar

A weekly, automatically generated digest of public research and releases on:

- Agent fine-tuning (SFT, RL / GRPO, trajectory synthesis, distillation)
- Tool-calling and multi-step agent reliability
- Quantization and efficient inference for agents
- Enterprise / ERP agent benchmarks (ERP-Bench, τ²-bench, BFCL, EnterpriseBench, …)
- Releases of key open-source training and inference frameworks

**Read it as a website: https://chenglong89.github.io/research-radar/**

All content is drawn from public sources only (arXiv, Hugging Face, lab blogs, GitHub releases).

## Layout

| Path | Purpose |
|---|---|
| `digests/YYYY-MM-DD.md` | Weekly digest |
| `competitors/YYYY-MM-DD.md` | Bi-weekly roundup of public enterprise/ERP AI product announcements |
| `config/topics.yaml` | Topics, keywords, sources and relevance criteria — edit to steer the digest |
| `state/seen_papers.json` | Items already covered, used to avoid repeats |
| `PROMPT.md` | Instructions each scheduled run follows |
